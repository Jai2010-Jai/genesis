How it works

From a sentence to an installable app, in five steps.

Genesis is a small app factory that runs on your computer. AI does the writing. A real compiler and a strict checker decide whether it's done.

Genesis Studio

Make apps from the couch.

Genesis Studio is a tiny companion app (about 1 MB) that turns your phone into a remote control for your computer's app factory.

  • Pair in seconds. Scan a QR code on your computer's screen — that's it.
  • Watch it build live. See every stage as it happens.
  • Install with one tap, or share the APK with family and friends.
  • Your key stays home. The phone never sees your AI key; all the heavy lifting happens on your computer.

Built to be trusted

AI writes the code. It doesn't get the keys.

Genesis treats AI output as untrusted until it's proven safe. Here's what's enforced on every single build.

Locked template

The AI writes Kotlin only

Build settings, permissions and dependencies come from Genesis, never from the model.

No back doors

Risky APIs are blocked

No networking, web views, reflection, native code or running other programs inside generated apps.

No permissions

Apps can't ask for more

Generated apps ship with zero Android permissions, and the APK is checked to prove it.

Your secrets

Your key never leaves

The Gemini key lives on your computer, is stripped from the build, and never reaches the browser or your phone.

Isolation

Every build in its own folder

Builds run with a minimal environment and a hard timeout. Code is compiled, never run, on your machine.

Proof, not promises

Verified or not shown

Success is claimed only when Gradle passes and the APK passes zip, package, permission and signature checks.

Straight talk

What it does today — and what it doesn't yet.

✓ Works today

  • Native Android apps from a single description
  • Automatic error repair during the build
  • Live progress, full build logs and history
  • Install from your phone with Genesis Studio
  • Apps that save your data on the device

✗ Not yet

  • Editing an app after it's made (“make it green”)
  • Apps that use the internet, photos or custom images
  • Play Store publishing — APKs are test (debug) builds
  • Automatic testing of how the app behaves on screen
  • Accounts for sharing one Genesis with many people

Get started

Set it up once. Make apps forever.

Genesis runs on your own Mac or PC. The first build fetches its tools (about four minutes); after that, apps take a minute or two.

  • Python3.10 or newer
  • JavaJDK 17
  • AndroidSDK command-line tools (no Android Studio)
  • AIA free Gemini API key from Google AI Studio

Run python -m genesis doctor any time — it checks your setup and tells you exactly what's missing.

# 1. Install
$ uv venv --python 3.12 .venv
$ uv pip install -r requirements-dev.txt

# 2. Add your Gemini key
$ cp .env.example .env
$ python -m genesis doctor

# 3. Open the dashboard
$ python -m genesis
  → http://127.0.0.1:8765

# …or build straight from the terminal
$ python -m genesis build \
    "A flashcards app with decks" --name CardCraft

Questions

Good things to ask.

Do I need to know how to code?

No. You describe the app in your own words. Genesis handles the code, the build and the checks. Setting it up the first time involves copying a few commands into a terminal.

Is it a real app, or a web page in disguise?

A real one. Genesis produces native Kotlin and Jetpack Compose — the same technology professional Android apps use — compiled into a standard .apk.

How much does it cost?

Genesis itself runs on your machine. It uses the Gemini API, which has a free tier with rate limits. One app is usually one AI call plus up to two repairs (roughly 10–40k tokens). Note that a Google AI Pro subscription doesn't include API credits.

How do I put the app on my phone?

Use Genesis Studio and tap Install, or copy the .apk to your phone and open it. Android will ask you once to allow installing apps from that source.

Can I put it on the Play Store?

Not yet. Today's apps are debug-signed test builds — perfect for you, your family and your friends. Release signing is on the roadmap.

Does it work on iPhone?

Not at the moment. Genesis builds Android apps, and Genesis Studio is an Android app.
